How the data works

  • Both tools read and write to the same Supabase project — changes appear on every device within seconds.
  • Vendor checklist state is stored one row per month under vendor:YYYY-MM, so closing a month archives it automatically.
  • If the sync indicator shows Offline, the database has auto-paused after inactivity and needs to be restored before changes will save.
